# Codex：血液病科研与数据分析

本项目用于血液病科研、生物信息学和队列数据分析，组织 R、Python 分析代码、可复用脚本、研究文档及可公开的分析产物。

## 项目结构

| 目录 | 用途 |
| --- | --- |
| `R/` | R 分析代码 |
| `Python/` | Python 分析代码 |
| `scripts/` | 数据处理及工作流脚本 |
| `results/` | 经审核、可公开的汇总结果 |
| `figures/` | 经审核、可公开的图表 |
| `docs/` | 研究设计、数据字典模板和分析说明 |

## 数据与隐私

请勿将患者级数据、原始临床数据、身份标识、密钥或其他敏感信息提交到仓库。研究数据应保存在仓库之外、经授权且符合机构要求的存储位置，并通过本地配置引用。

`.gitignore` 提供常见数据及敏感文件的忽略规则，但不能替代人工审核。提交前请检查暂存区；结果和图表也应检查是否包含可识别信息。

## 开发说明

当前仓库仅包含项目骨架，尚未指定依赖或分析流程。后续添加分析时，请记录运行环境、依赖版本、输入要求及复现步骤，并使用合成数据或允许公开的示例进行测试。
